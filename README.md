# Chicago Taxi Trips: Exploratory Data Analysis & Hypothesis Testing

Exploratory data analysis and hypothesis testing on Chicago taxi trip data to evaluate how external factors (such as weather conditions and drop-off locations) impact trip duration and frequency.

---

## 🛠️ Technologies & Tools
- **Language:** Python
- **Data Manipulation:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Statistical Analysis:** SciPy (Student's t-test)
- **Data Extraction:** SQL

---

## 📊 Key Highlights & Project Steps
1. **Exploratory Data Analysis (EDA):** Identified top taxi companies by number of rides and analyzed primary drop-off neighborhoods in Chicago.
2. **Data Cleaning:** Verified data types, checked for missing values, and processed records retrieved via SQL queries.
3. **Hypothesis Testing:** Conducted a two-sample t-test to evaluate whether the average duration of rides from the Loop to O'Hare International Airport changes on rainy Saturdays compared to clear Saturdays.
